# Donkey Kong Spilaútskýring
Spilið er mjög svipað spilinu snakes and ladders, leimaður ýtir á Græna takkann til þess að kasta teningnum og fer jafn marga reiti áfram og talan segir. Ef að þú lendir á Stiga þá ferðu upp hann og ef að þú lendir á banana farðu á síðasta banana reit bakvið þig. 
Special, ef að ljósið á takkanum blikkar þá ferðu að næsta stiga og ferð upp hann. hann sem kemst að end fyrst vinnur.
